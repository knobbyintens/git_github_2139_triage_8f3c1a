# Atlas Platform

Atlas is the workspace platform used by enterprise customers for document
collaboration, search and billing.

## Components

- `auth` - identity, SSO and session handling
- `api` - public REST and batch APIs
- `search` - indexing and query services
- `media` - file uploads and image processing
- `platform` - feature flags and operator tooling
- `realtime` - WebSocket notifications
- `gateway` - edge routing and rate limiting

## Release planning

Release planning metadata is recorded in issue descriptions. Release managers
read that metadata when preparing the release notes.
